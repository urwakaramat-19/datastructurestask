# Data Structures Tasks in Java

## About the Project
This repository contains my Data Structures and Algorithms (DSA) tasks implemented using Java. The purpose of this project is to understand data structures, learn their operations, and improve problem-solving skills through practical implementation.

## Topics Covered

- **Two-Dimensional Array:** Storing and displaying data in rows and columns.
- **Stack Using Linked List:** Implementing push, pop, peek, and display operations.
- **Queue Using Linked List:** Implementing enqueue, dequeue, peek, and display operations.
- **Circular Queue Using Array:** Implementing a circular queue with efficient insertion and deletion.

## Technologies Used
- Java
- Visual Studio Code
- GitHub

## How to Run the Programs

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the Java file you want to execute.
5. Compile and run the program using the terminal.

Example:

```bash
javac CircularQueue.java
java CircularQueue
```

Replace `CircularQueue.java` with the name of the Java file you want to run.

## Learning Objectives

- Understand arrays and linked lists.
- Learn stack and queue operations.
- Understand FIFO and LIFO principles.
- Practice implementing data structures in Java.
- Improve logical thinking and programming skills.
